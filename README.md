## Propósito del repositorio

Este repositorio es la plantilla de entregas de la asignatura. Cada grupo debe hacer un **fork** y utilizarlo para entregar:

- Los **informes** de los Trabajos Prácticos.
- El **código fuente** de los proyectos asociados.

---

## Cómo empezar

1. Hacer un **fork** de este repositorio a la cuenta de GitHub de uno de los integrantes.
2. Agregar al otro integrante como colaborador (*Settings → Collaborators*).
3. Clonar el fork en la computadora local.
4. Completar la sección **Datos del grupo** de este archivo y hacer el primer *commit*.
5. Informar a la cátedra la URL del fork.

---

## Estructura del repositorio

```
.
├── README.md
├── TP1/
│   ├── informe/      ← informe del TP (PDF)
│   └── proyecto/     ← proyecto completo
├── TP2/
│   ├── informe/
│   └── proyecto/
└── ...
```

- Cada Trabajo Práctico va en su propia carpeta `TPn`.
- El informe se entrega en **PDF** dentro de `informe/`.
- En `proyecto/` va el proyecto completo, listo para compilar. No subir carpetas de compilación (`Debug/`, `Release/`, binarios, etc.).

---

## Normas de entrega

- La entrega se considera realizada con el último *commit* subido al fork antes de la fecha límite.
- Usar mensajes de *commit* descriptivos (por ejemplo: `TP2: agrega manejo de interrupciones del timer`).
- Ambos integrantes deben participar en el repositorio; se tendrá en cuenta el historial de *commits*.
- El código debe estar comentado y el informe debe explicar el diseño, no solo mostrar resultados.
