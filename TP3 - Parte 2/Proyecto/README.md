# Proyecto

En esta carpeta va el **proyecto completo** del Trabajo Práctico, listo para importar y compilar.

## Datos del proyecto

> Completar en cada TP.

| Campo        | Dato                              |
|--------------|-----------------------------------|
| Placa        | Ej.: FRDM-XXXXX                   |
| IDE          | Nombre y versión                  |
| SDK          | Versión (si corresponde)          |

## Qué subir

- Archivos fuente (`.c`, `.h`) y de ensamblador (`.s`), si los hay.
- Archivos de configuración del proyecto propios del IDE, necesarios para importarlo.

## Qué NO subir

- Carpetas de compilación (`Debug/`, `Release/`, `build/`).
- Binarios y archivos generados (`.o`, `.elf`, `.axf`, `.bin`, `.hex`, `.map`).
- Archivos personales del IDE o del sistema operativo.
