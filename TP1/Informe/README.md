# Informe

En esta carpeta va el **informe del Trabajo Práctico** en formato **PDF**.

## Nombre del archivo

```
TPn_Apellido1_Apellido2.pdf
```

Ejemplo: `TP2_Gomez_Perez.pdf`

## Contenido mínimo del informe

1. **Carátula**: asignatura, número y título del TP, integrantes, año de cursado.
2. **Objetivo**: qué se pide resolver.
3. **Desarrollo**: diseño de la solución (diagramas en bloques, diagramas de estados, diagramas de flujo, configuración de periféricos, cálculos).
4. **Resultados**: pruebas realizadas y lo que se observó (capturas, mediciones, fotos del montaje).
5. **Conclusiones**: dificultades encontradas, cómo se resolvieron y posibles mejoras.

## Recomendaciones

- No pegar el código completo en el informe: hacer referencia a la carpeta `proyecto/` y mostrar solo los fragmentos necesarios para explicar el diseño.
- Las figuras deben tener número y epígrafe, y estar citadas en el texto.
- Subir solo el PDF final, no los archivos fuente del procesador de texto.
